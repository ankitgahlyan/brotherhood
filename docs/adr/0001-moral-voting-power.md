# Voting power is moral, not capital-weighted

BrotherHood's consensus instrument is the FI jetton, but voting power for Authority elevation is deliberately a fixed per-Account endowment (10 votes), not weighted by FI balance or staked capital. This makes authority a measure of reputation and trust rather than wealth, which is the point of a network state: moral consensus precedes economic consensus. It is hard to reverse because any future stake-weighted voting would require a new governance model; and it is surprising because most token communities weight votes by holdings.
